# Tooling available in this repo

`rust-analyzer` is installed via rustup (`rustup component add rust-analyzer`) and works from
the CLI, so symbol work does not have to fall back to grep:

    rust-analyzer diagnostics .        # semantic diagnostics across the crate

Prefer it over textual search when the question is about symbols — whether a name is used,
where it is defined, what a change breaks. `cargo build --all-targets` is the other half:
plain `cargo build` does not compile test targets, so unused imports in tests stay invisible.

Gates this repo holds to, all currently clean:

    cargo test                      # 192 passing
    cargo build --all-targets       # 0 warnings
    cargo fmt --check               # 0 diffs
    cargo doc --no-deps             # no unresolved links
    ./scripts/run_upstream_tests.sh # dspy's own pytest against this crate
